- Незавершённые решения: `<ссылки или список>`

Этот файл содержит постоянные подтверждённые ограничения проекта, а не текущий статус. Root поручает исполнителям любую задачу разработки, включая исследование, документацию и ревью; функциональный код пишут исполнители, root собирает контекст, проверяет результат и интегрирует его. Root утверждает декомпозицию и brief исполнителей, назначает точные файлы и единственного writer, принимает интеграцию и ведёт общий контекст. Исполнители не расширяют scope самостоятельно.

Обязательны правила [AGENTS.md](AGENTS.md) и [оркестрации](docs/agent-orchestration.md). Автор пакета не принимает его единолично. Не выполнять неразрешённые SSH, production операции, deploy или изменения внешних данных. Не добавлять секреты в код, логи и отчёты. Не создавать новые Git-ветки без отдельного явного распоряжения; stage/commit/push выполняет пользователь.
