> Исполнение делегированным автором и независимое кросс-ревью; root ведёт интеграцию и live execution. Git-ветки, stage, commit и push запрещены.

**Цель:** восстановить штатное чтение исхода неопределённой заявки через реальный Core HTTP API и получить причину системного HOLD SIBN через штатную операторскую проекцию.

**Архитектура:** HTTP-параметры разбираются на границе Core в UUID/положительное целое, затем проверяются прежним строгим SubmitAttemptRequest. Ownership, origin pair, финансовые DTO и UNKNOWN lifecycle сохраняются. Причина HOLD читается существующим repository/API read model; не делать ручных запросов к PROD БД и не менять состояние для диагностики.

**Стек:** существующие FastAPI/Pydantic, pytest, изолированная SQLite; новых зависимостей и DDL нет.
