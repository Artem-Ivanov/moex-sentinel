## Уточнения после независимого ревью D1

- Read-only `active` повторяет существующую durable policy Worker для соответствующего окружения: broker terminal status сам по себе не означает завершение intent. Незавершённые terminal/FAILED rows должны сохранять приоритет перед недавними finalized rows. Торговая политика не меняется.
- Worker выдаёт сохранённые `limit_price` и `executed_price` раздельно. Не вычислять точную цену исполнения приблизительно из суммы.
- `execution_snapshot` сверяет также `fact_instrument_id` и `lot_size` с Core. Несовпадение не даёт финансовых rows. UNKNOWN с отсутствующим trusted principal сохраняет причину `UNAUTHENTICATED_SOURCE`.
- Предварительные размеры optional коллекций проверяются до вложенной валидации. Явный `execution_diagnostics:null` эквивалентен отсутствующему полю. Ошибки cleanup не должны пропускать закрытие read-only соединения.
- Core выдаёт acceptance envelopes для всех видимых order/event/execution fact IDs, максимум `3*limit`, а не произвольные первые `limit` envelopes. Это доказательство приёма Core, не доставки ACK Worker.
- Worker `intent.fact_execution_id` — идентификатор сущности исполнения, не сообщения outbox. Связь: `Worker.fact_execution_id == Core.executions[].execution_id`, затем `fact_id` этой строки связывается с `accepted_envelopes[].fact_id/event_id` и kind `TRADE_EXECUTION_RECORDED`. Источники: Worker `storage/repository.py::_append_execution_graph`, `storage/fact_outbox.py::append`, Core `services/trading_fact_mapping.py`.
- Persisted Core-поля включают price, комиссии, decision/process и reservation runtime/generation; текущие scope units отделены от исторических единиц сохранённого decision. При отсутствии исторических единиц выводить неизвестное, не подменять их текущим каталогом.

Источники замечаний: независимые `audit_review_20261020` и `audit_architect_20261020`; локальный receipt — `develop/.planning/2026-10-20-trading-recovery-implementation/task-1-early-review.md`. Эти уточнения входят в исходную задачу финансовой корреляции и не разрешают live recovery.
